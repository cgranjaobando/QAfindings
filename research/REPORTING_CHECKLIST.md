# Control de reporte científico

Mapa propio de verificación inspirado en [R4-R6](../references/REFERENCES.md); no reproduce las listas completas ni acredita cumplimiento.

| Área | Evidencia requerida | Estado inicial |
| --- | --- | --- |
| Problema y contribución | Pregunta delimitada; revisión de antecedentes | Borrador |
| Población y muestra | Elegibilidad, canales, fechas, autoselección | Planificado |
| Instrumento | Versión, desarrollo, revisión y piloto | Revisión pendiente |
| Ética | Decisión independiente, consentimiento, riesgos, contacto | Pendiente; impide campo |
| Encuesta web / CHERRIES | Invitación, plataforma, pantallas, omisiones, duplicados y métricas de participación realmente observables | Pendiente |
| Encuestas / ACM SIGSOFT | Justificación de medición, faltantes, alcance y desviaciones | Borrador |
| Entrevistas / COREQ | Rol/experiencia del investigador, relaciones, selección, contexto, registro, análisis y reflexividad | Pendiente |
| Resultados | Denominadores, incertidumbre apropiada, ningún dato fabricado | Sin datos |
| Integración | Matriz de convergencias y divergencias sin enlace individual | Pendiente |
| Interpretación | Alternativas, límites de causalidad y generalización | Planificado |
| Ciencia transparente | Materiales, versiones, restricciones y código comprobado | En construcción |
| Publicación | Autoría humana, conflictos, financiación, uso de IA, revisión editorial | Pendiente |

La ausencia de métricas de visitantes únicos se informará si la privacidad impide medirlas. No se activará rastreo para completar una lista. El muestreo voluntario no permite declarar representatividad por alcanzar una cifra de participantes. Las recomendaciones se aplican con justificación contextual, no como certificación automática.
