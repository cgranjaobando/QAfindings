# Política de datos

**Esta carpeta no contiene ni recibirá datos de participantes.** Tampoco habrá ejemplos derivados de respuestas reales.

Permitido en el repositorio: diccionario/esquema, generadores completamente sintéticos, reglas de análisis y, cuando existan y se aprueben, agregados/síntesis con revisión de divulgación. No permitido: respuestas por persona, contactos, IDs del proveedor, IP, marcas horarias, empresa, transcripciones, grabaciones o exportaciones privadas.

El script de demostración genera observaciones ficticias en memoria. Sus números solo comprueban el funcionamiento del código y nunca pueden citarse como hallazgos. La marca `is_synthetic` debe ser verdadera en esas observaciones; no mezclar con datos reales.

Las entradas y salidas reales se almacenarán cifradas fuera del checkout y de carpetas sincronizadas públicamente. La revisión humana debe comprobar ausencia de reidentificación por combinaciones, texto y comparación entre versiones. El código no garantiza anonimato ni autoriza publicar sus salidas.
