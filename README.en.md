# QAFindings

**Research-protocol draft v0.1.0. No recruitment, participant data, findings, ethics approval, external preregistration, or peer-reviewed paper yet.**

QAFindings studies reported quality-assurance practices, opportunities to influence decisions, and delivery pressure in software teams. It does not assume that QA and Agile are compatible or incompatible in every organization. Professional titles are not treated as proof of actual assurance practices.

The first proposed phase includes a Spanish-language voluntary survey and separate confidential interviews. Participants from testing, engineering, product and leadership are sought only after the launch conditions are met. The unit of analysis is a person's account of a reference team, not an audited company. Results will not estimate the percentage of all companies performing QA or establish macroeconomic causality.

Public materials include the protocol, instruments, analysis plan, code and manuscript-in-progress. Real respondent-level records, contacts, employer names, internal tickets, transcripts and recordings must never enter this repository or its issues. Public GitHub contributions are identifiable; they are not an anonymous participation channel.

Start with the [Spanish project index](README.md), [protocol](research/PROTOCOL.md), [privacy plan](ethics/PRIVACY.md) and [launch checklist](ethics/LAUNCH_CHECKLIST.md). An English survey would require a separately reviewed translation and pilot; this summary does not imply bilingual instrument validation.
